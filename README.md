# 公基试卷生成器

事业单位考试 · 公共基础知识 · 智能组卷工具

## 功能

- **题库管理** — 添加、编辑、删除题目，支持单选题、多选题、判断题
- **智能组卷** — 自定义题型分布和套数，按知识点标签筛选范围，随机抽题
- **预览测试** — 内置交互式答题界面，实时评分，答案解析
- **导入导出** — 支持从标准试卷 HTML 导入题库，导出题库 JSON 或独立交互试卷 HTML

## 使用

1. 用浏览器打开 `公基试卷生成器.html`
2. 在"题库管理"中添加或导入题目
3. 在"试卷生成"中配置组卷参数，点击"随机组卷"
4. 在"预览测试"中答题验证
5. 在"导入导出"中导出试卷 HTML 或题库 JSON

## 题库导入

支持导入符合以下格式的试卷 HTML 文件：
- 包含 `const PAPERS = {...}` 数据结构的页面
- 每道题目格式：`{s: "single|multi|judge", q: "题干", o: ["选项"], a: [答案索引], e: "解析"}`

## 技术

纯前端单页应用，无依赖，所有数据存储在浏览器 localStorage 中。
