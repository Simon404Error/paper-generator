# 试卷生成器

试卷生成 · 智能题库

## 功能

- **题库管理** — 添加、编辑、删除题目，支持单选、多选、判断三种题型，批量选择和删除
- **智能组卷** — 自定义题型分布和套数，按知识点标签筛选范围，随机抽题
- **预览测试** — 内置交互式答题界面，实时评分，答案解析
- **导入导出** — 支持从标准试卷 HTML 导入题库，导出题库 JSON 或独立交互试卷 HTML

## 使用

下载 `index.html`，用浏览器打开即可使用。

1. 在「题库管理」中添加或导入题目，勾选复选框可批量删除
2. 在「试卷生成」中配置组卷参数，点击「随机组卷」
3. 在「预览测试」中答题验证
4. 在「导入导出」中导出试卷 HTML 或题库 JSON

## 题库导入

支持导入符合以下格式的试卷 HTML 文件：

- 包含 `const PAPERS = {...}` 数据结构的页面
- 每道题目格式：`{s: "single|multi|judge", q: "题干", o: ["选项"], a: [答案索引], e: "解析"}`

## 导入模板

下载 `题库导入模板.json`，按格式填写题目后，在「导入导出」中导入即可。

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `s` | string | 题型：`single` 单选题 / `multi` 多选题 / `judge` 判断题 |
| `q` | string | 题目内容 |
| `o` | array | 选项列表，判断题固定为 `["正确", "错误"]` |
| `a` | array | 正确答案索引，A=0, B=1, C=2... 多选题可多个 |
| `e` | string | 答案解析（可选） |
| `tag` | string | 知识点标签，逗号分隔（可选） |

## 技术

纯前端单页应用，无依赖，数据存储在浏览器 localStorage 中。
